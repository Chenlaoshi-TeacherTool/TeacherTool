# Class Pet Points artwork

The four pet atlases were generated with Codex's built-in ImageGen tool for the Class Pet Points local classroom tool. They are original project assets and are not copied from the product screenshot that inspired the feature.

## Shared production prompt

> Use case: stylized-concept. Asset type: web game pet sprite atlas. Create six completely original, cheerful classroom pet characters in a polished soft 3D children's game sticker style. Use rounded toy-like shapes, expressive friendly faces, crisp silhouettes, tactile fur, feathers, skin, or scales, and vivid harmonious colors suitable for elementary-school students. Arrange the pets in an exact 3-column by 2-row atlas, one full-body pet centered in each equal cell, with generous consistent padding, no overlap, the same scale, and a front three-quarter view. Use soft colorful gradient vignettes, bright welcoming studio light, and preserve the listed order from left to right across the top row and then the bottom row. No grid lines, text, letters, numbers, accessories, logos, trademarked characters, or watermark. Avoid photorealism, scary expressions, a dark mood, cropped features, uneven spacing, and extra animals.

## Atlas character prompts

- `pet-atlas-01.webp`: floppy-eared golden puppy; mint-and-cream kitten; lavender lop rabbit; coral red panda cub; turquoise baby dragon; round indigo owl chick.
- `pet-atlas-02.webp`: sunshine-yellow fox kit; sky-blue spotted fawn; lime-green hedgehog; bright pink squirrel; honey-brown bear cub; teal-and-gray raccoon cub. Match atlas 01's style and layout.
- `pet-atlas-03.webp`: orange-and-cream hamster; purple-and-white guinea pig; rosy-pink lamb; vivid violet alpaca cria; sunshine-yellow duckling; bright aqua penguin chick. Match atlas 02's style and layout.
- `pet-atlas-04.webp`: bubblegum-pink axolotl with frilly gills; rainbow-pastel baby unicorn; deep-blue baby seal with tiny star-like spots; bright green baby turtle; coral-and-gray koala joey; golden-orange cloud-maned lion cub. Match atlas 03's style and layout.

## Web treatment

Each generated 1536×1024 atlas was optimized to WebP for the website and is displayed as six equal 512×512 sprite cells. Growth is represented with egg, cracked egg, baby, chubby, cute adult, and sparkle forms. Teacher-controlled Christmas, Halloween, and Lunar New Year overlays decorate the pet without replacing the animal or changing its points.
