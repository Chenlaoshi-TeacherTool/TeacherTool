How to use Multilingual Vocabulary Library in class

Save focused vocabulary lists for later use in games, cards, booklets, and printable activities. Chinese, pinyin, and English fields are supported.

Best for: Teacher tool · K–12 Prep time: 5–10 minutes per list

What is this tool?

The library turns repeated typing into a reusable collection. It is especially useful for language teaching, but any teacher can store terms, optional pronunciation notes, and short definitions. Lists are saved in the current browser.

How to use it

  1. Keep each list connected to one clear goal, such as “Cell Structure: 12 Core Terms.”
  2. Check spelling, pronunciation, and definitions before saving.
  3. Use a name that includes the course, unit, and level so the list is easy to find later.

Classroom example: one list, three uses

On Monday, build a twelve-term unit list and run a quick recognition check. On Wednesday, use the same terms in a spinner or review game. On Friday, turn them into a mini booklet for retrieval practice.

Teacher tips

  • Keep a core list to 8–16 terms when students are new to the topic.
  • Separate words students should recognize from terms they must spell or define precisely.
  • Browser data can be cleared, so export or back up important lists.
